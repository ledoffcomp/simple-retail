# 🚀 Инструкция по загрузке на хостинг и передаче клиенту

Проект полностью готов для размещения в интернете или сборки в настольное приложение.

---

## 💡 Что лучше для передачи клиенту на пробу?

| Критерий | 🌐 Ссылка в интернете (Хостинг) | 💻 Файл приложения (.exe) |
| :--- | :--- | :--- |
| **Удобство для клиента** | ⭐⭐⭐⭐⭐ **Идеально**. Кликнул по ссылке — и сразу тестирует (с телефона, планшета или любого ПК). | ⭐⭐ Нужно скачивать архив, распаковывать, запускать. |
| **Предупреждения Windows** | **Нет.** Открывается в обычном браузере. | ⚠️ Windows SmartScreen покажет синее окно: *«Неизвестный издатель»* (требует нажатия «Подробнее → Выполнить в любом случае»), что часто отпугивает клиентов. |
| **Тест со смартфона** | **Да.** Владелец бизнеса обычно смотрит демо прямо с телефона. | **Нет.** Работает только на Windows ПК. |
| **Когда использовать?** | **Для первой презентации и демонстрации.** Конверсия в 10 раз выше. | **Для установки в реальный магазин на кассу**, когда клиент уже согласился и нужен офлайн. |

**Рекомендация:** Для пробы отправьте клиенту **ссылку на веб-демо**. А когда он скажет: *«Супер, ставь в магазин»* — поставим офлайн-версию на его кассовый ноутбук.

## Вариант 1. Загрузка в облако за 3 минуты (Бесплатно / Быстро)

### Способ А: Через Render.com или Railway.app (Самый простой)
1. Создайте репозиторий на [GitHub](https://github.com) и загрузите туда эту папку.
2. Зайдите на **[Render.com](https://render.com)** (или Railway.app).
3. Нажмите **New → Web Service** и выберите ваш репозиторий.
4. Укажите параметры:
   * **Runtime:** `Node`
   * **Build Command:** `npm install && npm run build`
   * **Start Command:** `npm start`
5. Нажмите **Deploy**. Через 1 минуту вы получите рабочую публичную ссылку вида:  
   👉 `https://simple-retail-demo.onrender.com` — отправляйте её клиенту!

---

### Способ Б: На любой VPS сервер (Timeweb, Selectel, Beget, Ubuntu)
Если у вас есть собственный виртуальный сервер:
1. Скопируйте папку проекта на сервер.
2. Запустите через Docker (файл `Dockerfile` уже создан):
   ```bash
   docker build -t easy-retail .
   docker run -d -p 80:3001 --name retail-app easy-retail
   ```
3. Приложение сразу будет доступно по IP-адресу вашего сервера.

## Вариант 2. Как передать офлайн-версию для Windows (.exe / Папка)

Если клиенту нужно протестировать систему строго локально на своем рабочем компьютере:

1. **Самый надежный способ без ошибок:**
   * Запакуйте текущую папку `1C` в `.zip` архив (без папки `node_modules`).
   * Клиент распаковывает архив и просто запускает файл **`run.bat`**.
   * Программа сама поднимает сервер и открывает окно кассы.

2. **Сборка в единый Desktop .exe (Electron):**
   * Если требуется именно упакованный `.exe`-файл с иконкой на рабочем столе — мы можем подключить оболочку Electron/Tauri за 5 минут.
