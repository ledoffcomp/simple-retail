# 🛒 Простая Розница (Альтернатива 1С для ИП и малого бизнеса)

Современная, быстрая и понятная система для розничного магазина и кассы.
Спроектирована в эстетике **shadcn/ui** — без лишних окон, зависающих регистров, блокировок и потребности в постоянном привлечении 1С-программистов.

---

## ⚡ Быстрый запуск

1. Дважды кликните по файлу **`run.bat`** (или выполните команду `npm start`).
2. Программа автоматически запустится и откроет рабочий интерфейс в браузере по адресу: **http://localhost:3001**

> 📱 **Доступ со смартфона:** Чтобы открыть программу на телефоне или планшете, подключитесь к общему Wi-Fi магазина и перейдите по адресу `http://<IP-адрес-компьютера>:3001`.

---

## 🚀 Основные модули и возможности

### 1. Рабочее место кассира (РМК / Касса) — Клавиша `F1`
* **Поддержка сканеров штрихкодов:** Сканируйте штрихкод товара — он мгновенно попадает в корзину (фокус ввода всегда готов).
* **Горячие клавиши для быстрой работы без мыши:**
  * `F1` — Мгновенно перейти в РМК из любого раздела.
  * `F2` — Фокус в поле сканера / поиска товаров.
  * `F8` — Открыть окно оплаты чека.
  * `F4` — Отложить текущий чек (если покупатель отошел за забытым товаром).
  * `Esc` — Отмена / Закрытие окна.
  * `Enter` — Подтверждение продажи.
  * `Пробел` — Переход к следующему покупателю после пробития чека.
* **Прием любых оплат:** Наличные (с автоматическим расчетом сдачи и быстрыми купюрами +100, +500, +1000, +5000), Банковская карта, СБП / Перевод.
* **Печать товарных чеков:** Автоматически форматируется для кассовых термопринтеров (лента 58мм / 80мм) или обычных офисных принтеров А4 (`Ctrl + P`).

### 2. Каталог товаров и цены
* Штрихкоды (EAN-13), артикулы, единицы измерения (шт, кг, л, уп).
* **Встроенный генератор штрихкодов:** сгенерирует корректный EAN-13 в один клик.
* **Автоматический расчет доходности:** наценка в % и чистая маржа в рублях прямо при вводе закупочной и розничной цены.
* **Печать ценников:** готовые ценники со штрихкодом и ценой для полок.
* **Экспорт в Excel / CSV:** скачивание всей базы товаров в один клик.

### 3. Склад и закупки
* **Приходные накладные:** простое оприходование партии от поставщика (увеличивает остаток и обновляет себестоимость).
* **Быстрая инвентаризация и списание:** пересчитали фактический остаток на полке → программа сама рассчитала излишек/недостачу и обновила базу. Никаких сложных ордеров!

### 4. Кассовые смены и деньги
* Открытие смены с указанием начального размена.
* Внесение денег и изъятие выручки / оплата расходов из кассы (аренда, курьер, хозтовары).
* Расчет реальной суммы в ящике в реальном времени.
* **Закрытие смены (Z-отчет)** с фиксацией выручки, безнала и сверкой фактических наличных.

### 5. Аналитика для владельца (Дашборд)
* Выручка сегодня с графиком сравнения со вчерашним днем.
* **Чистая прибыль** точки за день (маржа за вычетом себестоимости проданного).
* Средний чек и количество чеков.
* График динамики за 7 дней.
* Лидеры продаж (топ ходовых товаров).
* Контроль минимальных остатков (какие товары пора заказать).

## 🔒 Надежность и Резервное копирование

* Все данные хранятся локально в файле **`data/retail.db`** (стандарт SQLite).
* Для создания полного бэкапа просто скопируйте файл `data/retail.db` на флешку или в облако.
* Если нужно посмотреть данные напрямую — файл открывается любой бесплатной программой (например, *DB Browser for SQLite* или *DBeaver*). Никаких бинарных закрытых форматов 1С.
